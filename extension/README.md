# Shopping Helper Chrome 확장 (원클릭 가격 기록)

북마클릿과 같은 일을 하지만 설치가 쉽고, 상품 페이지에 자동으로 📌 버튼이 뜹니다.

## 설치 (개발자 모드)
1. `node extension/build.mjs` (web 소스의 추출 로직에서 `content.js` 생성)
2. Chrome → `chrome://extensions` → 개발자 모드 켜기 → "압축해제된 확장 프로그램 로드" → 이 `extension/` 폴더 선택
3. 확장 아이콘 우클릭 → 옵션 → 배포한 앱 주소 입력 (예: `https://your-app.vercel.app`)

## 사용
- 상품 페이지에서 툴바의 확장 아이콘 클릭, 또는 페이지 오른쪽 아래 📌 버튼 클릭 → 앱의 `/capture` 가 새 탭으로 열리며 기록됨
- 지원: JSON-LD/OG 를 쓰는 대부분의 쇼핑몰 + 네이버 스마트스토어(상태 JSON) + 쿠팡/아마존(셀렉터). 못 찾으면 가격 직접 입력 창이 뜸

## 스토어 배포는 나중에
지금은 개발자 모드 로드만. 웹스토어 등록 시 `<all_urls>` 대신 쇼핑몰 도메인 목록으로 좁힐 것.
