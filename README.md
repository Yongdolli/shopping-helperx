# Shopping Helper

한국·중국·미국 쇼핑몰 가격을 모니터링하다가, 같은 상품이 **최근 90일 중앙값보다 10% 이상 싸지면** 알려주는 서비스.
폰·패드·PC 공용 PWA + Python 수집 워커 + Supabase.

## 바로 실행 (키 없이 데모 모드)

```bash
cd web
npm install
npm run dev          # http://localhost:5173  — 데모 상품 6개가 미리 들어 있음
```

```bash
cd worker
pip install -r requirements.txt
python -m worker demo   # 데모 상품 + 90일 이력 시드 (SQLite: worker/data/dev.db)
python -m worker run    # 1회 수집 → 판정 → 알림
python -m worker add "https://www.ebay.com/itm/123456789012"
python -m worker vapid    # 웹푸시 키 생성 (무료)
python -m worker digest --dry-run   # 대기 알림 다이제스트 미리보기
python -m worker report --dry-run   # 주간 요약 리포트 미리보기
pytest
```

## 운영 연결 순서

1. Supabase 프로젝트 생성 → SQL Editor 에서 `supabase/ALL_MIGRATIONS.sql`(합본) 을 한 번에 실행 (또는 `migrations/001~010` 을 번호 순서로)
2. `web/.env.local` 에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (Auth → Email 로그인 켜기)
3. `worker/.env` 에 `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` + 텔레그램/이메일/사이트 API 키 (`.env.example` 참고)
4. `python -m worker vapid` 로 웹푸시 키 생성 → 웹·워커 .env 에 등록 (설정 화면에서 "켜기")
5. GitHub 저장소 Secrets 에 같은 키 등록 → `github-workflows/*.yml` 을 `.github/workflows/` 로 옮기면 매시간 수집 + 아침·점심·저녁 다이제스트 + 월요일 아침 주간 리포트 (`push-to-github.cmd` 가 자동으로 옮김)
6. 웹은 Vercel/Netlify/Cloudflare Pages 에 `web/` 배포 (빌드 `npm run build`, 출력 `dist`)

## 사이트별 데이터 경로

| 사이트 | 어댑터 | 필요한 것 |
|---|---|---|
| 네이버 스마트스토어·브랜드스토어 | `adapters/naver.py` (페이지 상태 JSON, 12시간 간격, robots.txt 준수) | 없음 · 차단 시 북마클릿 |
| 쿠팡 | `adapters/coupang.py` (파트너스 API, 상품명 검색 매칭) | 무료 파트너스 키 · 상품명 필수 |
| eBay | `adapters/ebay.py` (Browse API) | 무료 개발자 키 |
| Best Buy | `adapters/bestbuy.py` | 무료 API 키 |
| 11번가 | `adapters/elevenst.py` (OpenAPI) | 무료 API 키 |
| 알리익스프레스 | `adapters/aliexpress.py` (Affiliate API) | 앱키/시크릿 |
| 그 외 (Walmart·Target·지마켓·다나와 등) | `adapters/jsonld.py` (페이지 JSON-LD/OG) | 없음 |
| Amazon·테무·네이버 가격비교 | 봇 차단 강함 — **북마클릿**(설정 화면)으로 본인 브라우저에서 기록 | 없음 |

새 사이트 추가: `worker/worker/adapters/` 에 `BaseAdapter` 상속 파일 하나 + `registry.py` 에 한 줄.

## v0.9 에 들어간 것

- **🔥 딜 탭** — 상품을 등록하지 않아도 뽐뿌·루리웹·클리앙·퀘이사존·에펨코리아 핫딜을 매시간 모아 보여줍니다(최근 7일). 사이트·검색·할인율순, "할인율 30%↑ 확인"·관심 키워드 필터, 게시글 열기·추적 전환.
  설정의 최소 할인율·관심 키워드에 맞는 딜은 아침·점심·저녁 다이제스트에도 들어갑니다. 표시 할인율은 게시글 기준이라 정가 부풀리기가 섞일 수 있고, 추적으로 넘기면 평소 가격 대비 판정이 붙습니다.

## v0.8 에 들어간 것

- **하루 3회 다이제스트** (기본 켜짐): 워커가 감지한 알림을 아침 08:00·점심 12:30·저녁 19:00(KST)에 모아 한 번에 보냅니다. 새 알림이 없으면 조용. 설정에서 끄면 즉시 발송. 앱 알림 탭엔 항상 바로 쌓입니다. 목표가 도달은 기본으로 즉시(설정에서 변경).
- **가족 공유**: 설정에서 태그(또는 전체) 단위 읽기 전용 링크를 만들어 보내면, 받은 사람은 로그인 없이 현재가·"지금 사도 됨" 판단을 봅니다.
- **주간 요약 리포트** `python -m worker report` — 지난 7일 알림 수, 지금 사도 되는 상품, 목표가 근접, 30일 내 세일, 구매·절약액, 정품 리스크, 중단 상품을 한 장으로. 텔레그램·이메일 전문 + 푸시 한 줄. 월요일 09:00 KST 크론(`weekly-report.yml`). 앱 알림 탭 상단에도 같은 카드.
- **판매자 이력 신호**: 90일 안에 판매자가 3회↑ 바뀌면 정품 리스크 +15, 5회↑ +25 (공식 판매자면 무시). 최저가 경쟁 셀러가 돌아가며 붙는 상품을 잡는다.
- 워커에도 세일 캘린더·30일 추세를 포팅해 알림 note 의 결정 문장이 앱 카드와 같아짐 ("N일 뒤 블랙프라이데이 — 기다려볼 만함", "더 떨어지는 중").
- Windows 콘솔(cp949)에서 한글·이모지 출력 깨짐 수정.
- **버그 수정 7건**: Supabase 상품 추가(upsert)가 인덱스 불일치로 항상 실패하던 문제(008 마이그레이션) · 극단값이 정상가로 돌아와도 '확정'되어 역대 최저를 오염시키던 문제 · SQLite 옵션 없는 상품 중복 등록 ·
  실패한 조회가 재조회 간격을 무시하고 매시간 재시도하던 문제 · 같은 해 세일 이벤트가 차트·실적에 두 번 나오던 문제 · 워커가 사이트 통화(KRW 페이지)를 반영하지 않던 문제 · 품절 상품에 "지금 사도 됨" 이 붙던 문제 ·
  계단식 급락을 하락 추세로 오인해 "더 떨어지는 중" 이라 기다리게 하던 문제(R² 게이트).
- **2차 검토 수정 8건**: 마이그레이션이 `create or replace view` 컬럼 순서 변경으로 42P16 실패하던 문제(drop 후 재생성, 전체 멱등화, `ALL_MIGRATIONS.sql` 합본, 실제 PostgreSQL 검증 테스트 추가) ·
  상품 재등록·북마클릿이 upsert 로 제목·정품확인·구매 상태를 덮어쓰던 문제 · 세일 확정 시 예전 파싱 오류 값까지 승격되던 문제 · 구버전 알림이 첫 다이제스트에 쏟아지던 문제(notified 백필) ·
  주간 리포트가 품절 상품을 "지금 사도 됨" 으로 넣던 문제 · 카드가 매 렌더마다 리마운트되던 문제 · 공유 페이지에서 홈으로 이동 시 로그인 게이트를 건너뛰던 문제 · Vercel 딥링크 404(`web/vercel.json`).
